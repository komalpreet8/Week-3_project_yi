# Week 3 Task: Integrating JavaScript for Interactive User Experience

## 1. Project Name
TechZone - Interactive Website

## 2. Objective
The objective of this project is to improve the user experience
of a webpage using JavaScript, DOM manipulation, and event handling.

## 3. Technologies Used
- HTML5
- CSS3
- JavaScript

## 4. Project Features

### Dark Mode
A button switches the website between light and dark themes.

### Product Details
Users can click the Show Details button to display additional
information about a product. They can hide the information again.

### Read More
The Read More button displays additional information in the About section.

### Contact Form Validation
JavaScript checks the name, email address, and message before
displaying a confirmation.

### Dynamic Year
JavaScript automatically displays the current year in the footer.

## 5. JavaScript Concepts Used

- DOM manipulation
- Event listeners
- Click events
- Form submission events
- Conditional statements
- Functions
- Class manipulation
- Input validation

## 6. Implementation

HTML provides the webpage structure.
CSS styles the website and makes it responsive.
JavaScript adds interactive functionality.

The addEventListener() method detects user actions.
The classList.toggle() method switches the dark theme.
The textContent and hidden properties update webpage content.
The preventDefault() method prevents the form from reloading
the page during validation.

## 7. Testing

The following tests should be performed:

1. Click Dark Mode and check whether the theme changes.
2. Click Show Details on each product card.
3. Click Read More in the About section.
4. Submit the contact form without entering information.
5. Enter an invalid email address and check the error.
6. Enter valid-looking information and check the confirmation.
7. Test the layout on desktop, tablet, and mobile screen sizes.

## 8. Challenges and Solutions

Challenge: Updating webpage content without reloading.

Solution: Used DOM manipulation and event listeners.

Challenge: Preventing incomplete form submissions.

Solution: Added JavaScript validation for name, email, and message.

Challenge: Making the website easy to use on different devices.

Solution: Used CSS Grid, Flexbox, and media queries.

## 9. Conclusion

This project demonstrates how JavaScript can make a static webpage
interactive. It provides practical experience with DOM manipulation,
event handling, form validation, and integration of HTML, CSS,
and JavaScript.
